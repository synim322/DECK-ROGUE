## 1. Цель документа

Зафиксировать **JRPG-красивые**, но **дистанционно читаемые** силуэты для:

- DJ-протагониста  
- промоутера (briefing / onboarding)  
- **5 архетипов** танцпола (MVP может отгрузить 3, см. §10)  
- трёх состояний Hype: **calm → groove → peak**  
- босс-зала **The Signal** — особая толпа и силуэт площадки  

Игрок должен **без текста** понять: зал остыл, качает или на пике — по **форме позы** и **плотности** фигур, не только по неону.

## 2. Визуальный язык: «JRPG в неоновом подвале»

### 2.1 Референс-настроение (не копировать)

- **Силуэт:** Final Fantasy / Chrono Trigger NPC на клубной сцене — крупная голова/плечи, один **главный** аксессуар-силуэт (шляпа, антенна, наушники, шарф).  
- **Контраст:** тёмное тело (`Night`/`Panel`) + 1–2 неоновых акцента клуба; избегать «радуги на каждом пикселе».  
- **Эмоция:** поза читается с **24–32 px** ширины персонажа на экране (телефон в ландшафте, рука на расстоянии).

### 2.2 Запреты

- Размытие, субпиксельный джиттер, AI-шум вместо читаемого контура.  
- Строб как единственный маркер Hype (reduced flashing обязан оставлять смысл).  
- Детали лица < 3×3 px — лицо **силуэт + один блик**, не портрет.

### 2.3 Grayscale-приёмка

Каждый архетип и каждая Hype-поза проходят скриншот в **grayscale**: архетипы различимы, calm/groove/peak различимы по **силуэту** (руки, наклон, расстояние ног), не по hue.

## 3. Технические параметры

| Параметр | Значение | Комментарий |
|---|---|---|
| Reference canvas (клуб) | **480×270** logical | Полная сцена; зал в HUD сейчас **480×168** верхней полосы |
| Сетка | **8×8**, крупные формы **16×16** | Все координаты целые |
| PPU (Unity) | **16** (рекомендация v0.1) | Единый PPU для `SPR_*` персонажей одного масштаба |
| Filter | Point (Nearest) | Без mip blur |
| Pivot crowd | **низ по центру стоп** (foot) | Совпадает с `PixelClubView` `grounded` |
| Pivot DJ | **центр подиума / стоп** | Стоит за пультом, не перекрывает деки |
| Pivot promoter | **стоп** | Портрет / pre-club, не performance |

### 3.1 Размеры спрайтов (bbox, с прозрачностью)

| Роль | Ширина × высота | Заметки |
|---|---|---|
| **Crowd archetype** | **16×32** (foot…top) | Узкая колонка; на сцене ~8–10 px между центрами |
| **Crowd front row** (peak) | **18×36** | +2 px руки вверх; отдельный слой «передний ряд» |
| **DJ protagonist** | **32×48** | Канон master doc; наушники + силуэт плеч |
| **DJ (close-up portrait)** | **48×48** | Меню / result — опционально P1 |
| **Promoter** | **24×40** (bust) / **32×56** (full) | Briefing: bust достаточно для MVP |
| **The Signal — crowd unit** | **16×34** | +2 px «антенный» хвост / шип в силуэте |
| **The Signal — boss mass** | **до 96×40** | Композитная «волна» из 5–7 силуэтов, одна текстура |

Высота **от пола** (`y = foot` в координатах спрайта): тень/линия пола **не входит** в bbox.

### 3.2 Turnaround (персонажи с лицом к игроку)

| Ассет | Обязательные ракурсы | MVP |
|---|---|---|
| DJ protagonist | **Front** (основной), **¾ L**, **¾ R**; back — силуэт для shadow/pass | Front + ¾×2 |
| Promoter | **Front** (диалог), **¾** для жеста рукой | Front |
| Crowd archetypes | **Front only**; легальное зеркалирование по X | Front |
| The Signal crowd | Front + **вариант «синхронная волна»** (смещение 1–2 px по X) | Front |

**Правило JRPG-turn:** на ¾ сохранять **тот же** главный аксессуар с той же стороны (напр. наушники всегда читаются с внешней щеки), не «перепрыгивать» через голову.

### 3.3 Анимация — кадры на состояние Hype

Системные пороги (`HypeSystem` / `RunChrome`): **calm** Hype &lt; 40, **groove** 40–69, **peak** ≥ 70.

| Состояние | Имя в ассетах | Кадров | FPS @ 120 BPM | Содержание |
|---|---|---:|---|---|
| **Calm** | `Calm` | **2–3** | 2-step / фраза | Редкое покачивание, руки вниз / в карманах, плечи вперёд |
| **Groove** | `Groove` | **3–4** | удар на **beat 0** | Ритмичный шаг, одна рука вверх, корпус наклон 1 px |
| **Peak** | `Peak` | **4–6** | beat 0 + beat 2 bob | Прыжок (bob +4/+2 px), обе руки, опционально **cheer** кадр на drop |

**Именование кадров:** `SPR_Crowd_{Archetype}_{HypeState}_{00..nn}.png`  
Пример: `SPR_Crowd_Raeger_Peak_03.png`

**Синхронизация:** ключевые позы на **downbeat** (доля 1); между кадрами — смещение на 2 px по Y (как в коде `Bob`), без интерполяции «мылом».

### 3.4 Плотность толпы (читаемость на расстоянии)

| Hype band | Имя | Слой | Кол-во силуэтов (реф. код) |
|---|---|---|---|
| 0 | calm | sparse back | **5** |
| 1 | groove | packed back | **8** |
| 2 | peak | packed back + **front row** | **8 + 5** |

Архетипы **чередуются** в ряду (A B A C B…), не 8 копий одного файла подряд — иначе теряется JRPG-разнообразие.

## 5. DJ-протагонист

**ID:** `CHR_DJ_Protagonist`  
**Роль:** узнаваемый герой за пультом; косметика P1 не ломает силуэт.

### 5.1 Силуэт (must-read)

- **Наушники** — полный овал вокруг головы (главный маркер в 32 px ширине).  
- **Плечи** квадратные, чуть шире головы (JRPG hero chunk).  
- **Одна рука** на фейдере / vinyl — вторая скрыта за столом (экономия пикселей).  
- **Нет** лица-детализации: 2 px «блик» на щеке, остальное — тень капюшона или волос.

### 5.2 Палитра героя

- Куртка: `#2E3250` + outline `#151628`  
- Наушники: Deck A `#62A4F4` + rim `#F3F3EC` (1 px)  
- Кожа (если видна): `#C8A090` — **не** использовать для толпы

### 5.3 Позы (performance)

| Имя | Размер | Описание |
|---|---|---|
| `Idle` | 32×48 | Рука на пульте, лёгкий кивок 1 px |
| `Focus` | 32×48 | Наклон к активной деке (A или B tint на наушниках) |
| `Drop` | 32×50 | +2 px — рука вверх, **без** full-screen flash |

Turnaround: §3.2. Экспорт с пустым 2 px зазором снизу под линию подиума.

### 5.4 Косметика (P1)

Слои: **hair / jacket / headphones / gloves** — swap palette только на слое аксессуара; bbox не меняется.

## 6. Промоутер

**ID:** `CHR_Promoter`  
**Роль:** 1–3 реплики briefing; дружелюбный, не перекрывает HUD.

### 6.1 Силуэт

- **Планшет / бумажка** в левой руке — прямоугольник 6×8 px (читается как «бриф»).  
- **Жест правой рукой** — palm open (welcome), не указательный перец.  
- **Силуэт плеч** мягче, чем у DJ (менее «броня», больше плащ/пальто).

### 6.2 Палитра

## 7. Архетипы толпы (5)

Общая высота **16×32**, стопы на общей линии. Каждый тип имеет **те же три Hype-набора** (calm / groove / peak).

### 7.1 A — «Baseline» (`Crowd_A`)

**Танец:** вес на месте, минимальные жесты.  
**Аксессуар:** капюшон, руки в кармане на calm.  
**JRPG-читаемость:** треугольник капюшона сверху.  
**Отличие в groove:** одна рука из кармана, корпус 1 px в сторону.

### 7.2 B — «Raeger» (`Crowd_B`)

**Танец:** руки вверх раньше остальных на peak.  
**Аксессуар:** **большие наушники** (как у DJ, но меньше) — связь с музыкой.  
**Groove:** «в такт» — локоть 90°.  
**Peak:** обе руки + наушники не съезжают с головы (якорь силуэта).

### 7.3 C — «Fashion» (`Crowd_C`)

**Танец:** корпус, плечи волной.  
**Аксессуар:** **широкий ворот / шарф** — горизонталь 12 px (самый широкий силуэт в ряду).  
**Calm:** шарф опущен; **Peak:** шарф поднят как флаг (1–2 px выше головы).

### 7.4 D — «Industrial» (`Crowd_D`)

**Танец:** stomp — на groove ноги **шире** на 2 px.  
**Аксессуар:** жилет с клапанами (2 прямоугольника на груди).  
**Связь с миром:** tech / warehouse vibe без копирования реальных брендов.

### 7.5 E — «Vet» (`Crowd_E`)

**Танец:** economical — меньше прыжка, больше кивка.  
**Аксессуар:** **козырёк** или бейдж (1 px полоска на груди).  
**Нарратив:** «бывалый» клубнич; на calm почти статичен — контраст с Raeger на peak.

### 7.6 Таблица поз Hype (общая для A–E)

| Hype | Плечи | Руки | Ноги | Высота bob |
|---|---|---|---|---|
| calm | сгорблены | вниз / карман | вместе | 0 |
| groove | ровные | одна вверх | шаг | beat0: +2 px |
| peak | назад | обе вверх | врозь | beat0: +4, beat2: +2 |

На **clean transition / drop** (игровой cue) — **один кадр cheer**: ладони Mint `#5ED3B1` (4×4 px), как в `DrawPeak(..., cheer)`.

## 8. The Signal — босс-толпа

**Клуб:** `The Signal` (boss, сюжетный пик ночи).  
**ID:** `CHR_Crowd_Signal` / `BG_Club_TheSignal_CrowdMass`

### 8.1 Концепт

Зал ведёт себя как **один организм**: множество людей с **одинаковым ритмом** (не хаос Rave District). Визуально — **JRPG boss crowd**: силуэты слипаются в волну, но 5–7 «голов» всё ещё читаются.

### 8.2 Отличия от обычной толпы

| Аспект | Обычный клуб | The Signal |
|---|---|---|
| Синхрон | offset по индексу | **одинаковый фазовый bob** на всех |
| Аксессуар | разный | **антенна / шип** 2×6 px на макушке |
| Палитра | Neon Basement triad | §4.4 |
| Фазы босса | — | **Phase A** спокойный синк → **Phase B** split glitch (1 px сдвиг половины массы) |

### 8.3 Ассеты

1. **Unit** `SPR_Crowd_Signal_{Calm|Groove|Peak}_nn.png` — как архетип, но антенна обязательна.  
2. **Mass** `SPR_Crowd_Signal_Mass_Phase{A|B}_{state}.png` — ширина 96 px, для задника сцены.  
3. **VFX** (отдельный слой, additive): `VFX_Signal_Pulse_00..02` — **≤ 3 кадра**, выключается reduced flashing.

### 8.4 Hype на боссе

Те же три состояния, но **peak** визуально «опаснее»: больше **плотности** (не больше цветов) — добавить 2 силуэта в mass, не увеличивать яркость всего кадра.

## 9. Композиция в кадре (читаемость)

```
┌──────────────────────────────────────────── 480 ────────────────────────────────────────────┐
│  SPEAKERS │        CROWD (sparse → packed → +front)        │ SPEAKERS │
│           │   · · · · ·          NEON SIGN          · · · · ·           │
│           │              LAMPS (downbeat)                                │
│  DJ 32×48 │              PODIUM / DECKS (не перекрывать)                │
└──────────────────────────────────────────────────────────────────────────┘
```

- Толпа — **верхняя треть**; DJ — **слева у бокса**, не центр (не закрывает sign).  
- Минимальный зазор между силуэтами: **6 px** center-to-center на calm (код: шаг ~74 px на 5 фигур).  
- **Не** рисовать лица в масштабе &lt; 5 px.

## 12. Связь с геймдизайном

- **CrowdBand** не дублирует текст Hype: игрок видит **форму зала**, число — в HUD.  
- Ошибка (`Fault`) опускает позу к **calm** независимо от band — спрайты calm должны читаться «разочарование».  
- Успех (`Clean` / `Drop`) поднимает к **peak** на один такт — нужен **один** переходный кадр или cheer overlay.
